Data honesty

  • Token/cost: the cost_usd/token fields exist (AUD-007) but populate only once capture flows; shown as n/a until then.
  • "Hours" don't apply - agents are invoked, not clocked. Activations + active-days are the proxies; true compute-time needs a runner duration_ms field.
  • Scheduled-only telemetry: project/APS agents show few activations but real completed tasks - their sprint work runs outside this log.
